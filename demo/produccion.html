Smoke test contra producción

Esta página carga el widget desde el CDN real, no desde el build local. Sirve para verificar un deploy: es un origen distinto al del CDN, así que ejercita el camino de CORS que ninguna prueba local puede.

Qué mirar

  1. Que aparezca el botón flotante.
  2. Que al activar Fuente para dislexia cambie la tipografía. Si no cambia, falta Access-Control-Allow-Origin en el .woff2 — miralo en la consola.
  3. Que el filtro de color afecte a la paleta de abajo.
  4. Que seleccionar este texto muestre el botón «Leer».
